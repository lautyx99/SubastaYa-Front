# 💻 Frontend - Subasta Ya (React)

Este repositorio contiene la interfaz de usuario desarrollada en **React** (utilizando componentes de **React-Bootstrap**) para el trabajo..

---

## 📋 Requisitos Previos en la PC
Para poder ejecutar este proyecto, asegúrate de tener instalado previamente:
1. **[Node.js](https://nodejs.org/)** (versión LTS recomendada).
2. Un gestor de paquetes incluido con Node (como **npm**).

---

## ⚙️ Paso a Paso para Levantar el Proyecto

### 1. Clonar el repositorio y abrir la terminal
Abre una terminal (o consola) y sitúate en la carpeta raíz del proyecto frontend descargado.

### 2. Instalar las dependencias
Ejecuta el siguiente comando para descargar todos los paquetes y librerías necesarios (incluyendo React-Bootstrap y dependencias de enrutamiento/estilos):

npm install

### 3. Configurar la Conexión con la API (Backend)
Ubica el archivo de configuración de servicios o entorno (por ejemplo, en tus archivos de servicios o variables de entorno tipo .env / constantes de conexión).

Asegúrate de que la URL base de las peticiones HTTP apunte correctamente a la dirección local donde está corriendo la API del backend (por ejemplo: http://localhost:55976 o el puerto que arroje tu servidor backend).

### 4. Ejecutar la Aplicación en Modo Desarrollo
Inicia el servidor local del cliente ejecutando:

npm run dev
